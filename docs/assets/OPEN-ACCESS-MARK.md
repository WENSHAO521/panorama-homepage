# Open-access publication mark

Canonical runtime assets:

- `web/public/publishing/article-marks/open-access/open-access-mark.svg`
- `web/public/publishing/article-marks/open-access/open-access-mark.png`

The SVG is the unmodified source download. The PNG is a transparent fallback
generated from that SVG at 640 × 1000 pixels for article, PDF, and office-
document workflows.

Source and provenance:

- Source file: <https://commons.wikimedia.org/wiki/File:Open_Access_logo_PLoS_transparent.svg>
- Direct source URL used for the download: <https://upload.wikimedia.org/wikipedia/commons/7/77/Open_Access_logo_PLoS_transparent.svg>
- The source page attributes the design to PLOS and records the applicable reuse/licensing information.

Usage guardrails:

- Use this as an open-access publication indicator in article or PDF
  templates, not as a PLOS partner, index, or affiliation logo.
- Keep the artwork unchanged and do not recolor, redraw, or combine it with
  Panorama branding.
- Recheck the source page's current reuse and attribution requirements before
  publishing an article that carries the mark.
